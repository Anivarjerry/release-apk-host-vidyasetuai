# AGENTS.md - Customization Rules

## MANDATORY RULES FOR CODE GENERATION & EDITS

1. **Zero-Defect Deep Research**: Before writing or modifying ANY line of code, perform a complete, deep audit of imports, method signatures, project dependencies, and potential side effects. Never assume an extension method or library method exists without inspecting imports or dependencies.
2. **Every-Single-Line Rechecking**: Re-check every single modified line of code before presenting it. Guarantee zero syntax errors, zero unresolved references, and zero compilation defects regardless of how much research time is needed.
3. **100% Production-Grade Only**: All written code must be complete, robust, type-safe, and production-grade from day 1. No superficial snippet patches.
4. **Always Ask Before Modifying**: Never edit or touch any codebase file without explicit user confirmation and approval.
